    Interface KernelHooks

    What the kernel hands an add-on at install time. Add-ons reach the kernel only through this and the public kernel API, never through its internals: each bundle mangles property names on its own, so a name only survives the trip between bundles when it is declared here.

    The array members are hook lists. Add-ons push handlers; the kernel calls them in install order.
