Each guide answers one question about running micro frontends with FynMesh. It starts with the short answer, then shows the config and code behind it.

Versions and sharing

Multiple React Versions

Yes, React 18 and React 19 micro frontends can share one page. In FynMesh each app declares its React range and gets a copy that fits it.

 Share Dependencies by Semver

Declare shared modules with a semver range in each FynApp. The runtime picks a loaded version that fits, or loads its own copy when none does.

 Upgrade React Incrementally

Move micro frontends from React 18 to 19 one at a time. FynMesh runs both versions side by side, so each team ships its own upgrade.

 Legacy RequireJS Bundles

Legacy webpack AMD micro frontends loaded by RequireJS can get React and other shared libraries from Module Federation with no rebuild, and move to a new React major in stages.

Building

Micro Frontends with Rollup

Build each micro frontend with Rollup and rollup-plugin-federation, then load it by name with the FynMesh kernel. Works for React, Vue, Preact, Solid, Svelte and Marko.

 Module Federation Without Webpack

FynMesh brings Module Federation to Rollup with rollup-plugin-federation and a SystemJS based runtime, so you can share code between apps without webpack.
