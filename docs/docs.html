Reference

Kernel

How the FynMesh kernel loads FynApps, runs their lifecycle, wires middleware and connects apps with FynBus. API reference with the core concepts.

 federation-js

federation-js is the small runtime that loads federated modules in the browser. It resolves shared dependencies by semver range, so versions can coexist.

 rollup-plugin-federation

Configure the Rollup plugin that builds FynApps: what to expose, what to share, and how version ranges decide which copy of a library each app gets.

 Federation Inspector

A browser tool that shows which shared modules each app loaded and which version won. Use it to debug dependency sharing on a live page.
