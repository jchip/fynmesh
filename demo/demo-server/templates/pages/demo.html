What this demo shows

This page runs {{ fynApps | length }} FynApps on one page. They use React 18, React 19, Preact, Vue, Solid, Svelte and Marko. Different teams could build each one and deploy it on its own. The FynMesh kernel loads every app by name and starts it.

The point to notice is that two React versions run together. FynApp 1 uses React 19 and FynApp 2 uses React 18, and each gets the version its semver range asks for. Apps with matching ranges share one copy, so the page does not download the same library twice.

Scroll down to see each app render in its own panel. Open the in-page inspector to list the shared modules and who provides them. Each app mounts itself after the kernel has booted its dependencies, which can take a moment. Some apps show their own headings once they load.

Next steps: browse the feature overview, read the docs, or follow the guide Run Multiple React Versions on One Page. For a full layout built the same way, open the shell demo.
