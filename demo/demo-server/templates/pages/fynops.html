FynOps: a logistics console built from FynApps

FynOps is a demo app for FynMesh. It is a logistics operations console made of ten FynApps that one shell runs. The shell handles routing and layout, and each route loads its own feature app the first time you visit it.

Signing in

The app opens on a sign-in screen. The sign-in is simulated and no password is needed. Pick any listed user and press Sign in. The shipments, fleet and users are generated in your browser, and the data lives in SQLite running locally.

What to look at

Open Shipments for a 10k-row grid, Live Map for moving fleet positions, and Analytics for charts. Watch the network panel as you switch routes. React, AG Grid and ECharts load once and every feature app reuses them.

How it works

The page boots the FynMesh kernel and loads only the shell by name. The shell then loads shared providers and features by name and semver range. See the feature overview, the kernel docs and the guide on sharing dependencies by semver range.
